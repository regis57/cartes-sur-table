# Politique de sécurité

## Versions supportées

Seule la dernière version déployée en production (branche `main`) reçoit des correctifs de sécurité.

## Signaler une vulnérabilité

Merci de **ne pas** ouvrir d'issue publique.

Utilise le signalement privé de GitHub : onglet **Security** → **Report a vulnerability**.

Nous accusons réception sous 72 h et visons un correctif sous 30 jours selon la gravité.
