# Code de conduite

On joue aux cartes : on se parle avec courtoisie, on accueille les débutants, on critique
le code et jamais les personnes. Les remarques discriminatoires, le harcèlement et les
attaques personnelles n'ont pas leur place ici, ni dans les tickets, ni dans les
discussions, ni dans le jeu (qui, d'ailleurs, n'a pas de messagerie).

Un comportement contraire peut être signalé à l'adresse indiquée dans les mentions
légales du site. Le responsable du dépôt tranche, et peut retirer des contributions ou
bloquer des comptes.
